## Brand & Style

The design system establishes a high-performance biometric laboratory identity tailored for elite athletic conditioning and precision sports nutrition. The visual language merges aerospace technical instrumentation with stealth athletic brutalism. Designed for competitive athletes, sports scientists, and data-driven biohackers, the aesthetic projects clinical precision, unyielding intensity, and institutional efficacy.

The UI avoids decorative softness in favor of tactical telemetry: razor-sharp contrast ratios, dense numeric readouts, micro-grid line structures, and dark carbon substrates illuminated by high-frequency laser amber accents. Surfaces communicate engineered authority through high-density data typography, technical monospaced indices, and structural carbon containment layers.

## Colors

The system operates strictly within a deep carbon and obsidian luminance framework. Pure dark substrate layers establish the field, punctuated by laser amber as the dominant action state and tactical volt for telemetry thresholds.

- **Primary (`#FF5500` - Tactical Laser Amber)**: Primary call-to-actions, active state indicators, telemetry focus rings, critical data highlights, and biometric threshold warnings.
- **Secondary (`#CCFF00` - Electric Volt)**: Secondary performance indicators, verified lab certification stamps, nutritional potency tags, and positive physiological delta values.
- **Tertiary (`#00F0FF` - Ion Cyan)**: Cold telemetry metrics, molecular batch verification IDs, filtration timestamps, and ancillary analytical data.
- **Neutrals**:
  - `Base Obsidian Canvas`: `#0A0D12`
  - `Carbon Elevation Tier 1`: `#121620`
  - `Structural Containment Tier 2`: `#1A1F2C`
  - `Muted Tactical Boundary`: `rgba(255, 85, 0, 0.15)`
  - `Neutral Text High-Contrast`: `#FFFFFF`
  - `Neutral Text Data & Specs`: `#94A3B8`
  - `Neutral Text De-emphasized`: `#475569`

## Typography

The typographical architecture unites geometric velocity (`Sora`) with scientific clarity (`Hanken Grotesk`).

- **Display & Section Headers (`Sora`)**: Used for athletic impact statements, category titles, and nutritional metric values. Headlines feature tight negative tracking to enforce mechanical tension and aerodynamic compression.
- **Analytical & Body Copy (`Hanken Grotesk`)**: Rendered with neutral, open counters for sustained legibility within dense ingredient panels, clinical efficacy reports, and nutritional compound breakdowns.
- **Telemetry Labels & Overlines**: Rendered in uppercase with expanded tracking (`0.08em` to `0.12em`) using `Hanken Grotesk` (weights 600-700) to emulate aerospace flight deck instrumentation and laboratory equipment labeling.

## Layout & Spacing

The layout is built on a 12-column rigid analytical grid system configured for structural instrumentation displays. Grid columns maintain consistent containment boundaries to mimic technical instrumentation monitors.

- **Desktop (1200px+)**: 12 columns, 48px canvas margin (`margin`), 24px column gutter (`gutter`). Max content containment bounded at 1440px.
- **Tablet (768px - 1199px)**: 8 columns, 32px canvas margin, 16px column gutter. Data tables reflow into synchronized dual-column technical cards.
- **Mobile (< 768px)**: 4 columns, 16px canvas margin (`margin-mobile`), 12px column gutter (`gutter-mobile`). Visual telemetry charts convert to condensed linear readouts.
- **Spacing Rhythm**: Internal padding scales on a 4px baseline. Components employ high horizontal tension (`space-md` to `space-lg`) paired with compressed vertical intervals (`space-xs` to `space-sm`) to maintain an engineered, dashboard-like profile.

## Elevation & Depth

Elevation is established using tonal carbon layering, razor-thin structural borders, and directional back-glow illumination rather than soft blur-based shadows.

- **Base Field**: `#0A0D12` (Void canvas, unlit background).
- **Layer 01 (Structural Panels & Pods)**: `#121620` overlay with 1px border `rgba(255, 255, 255, 0.06)`.
- **Layer 02 (Telemetry Glass & Hover States)**: `rgba(26, 31, 44, 0.85)` with `backdrop-filter: blur(16px)` and a directional 1px perimeter stroke using `rgba(255, 85, 0, 0.3)`.
- **Laser Edge Accentuation**: Active or focused components deploy a hairline illumination outline (`1px solid #FF5500`) paired with a tight photonic aura (`box-shadow: 0 0 12px rgba(255, 85, 0, 0.25)`). Diffused ambient drop shadows are completely prohibited.

## Shapes

The design system enforces a precision-machined edge standard using a roundedness index of `1` (Soft: 0.25rem / 4px base). Elements feature minimal radius beveling to evoke machined tactical hardware, carbon composite plates, and precision sports instruments.

- **Base Interactive Items (Inputs, Buttons, Badges)**: `rounded` (`0.25rem` / `4px`).
- **Data Containers, Modal Overlays & Cards**: `rounded-lg` (`0.5rem` / `8px`).
- **Telemetry Indicators & Badges**: Fully sharp or micro-chamfered; circular radii are reserved solely for live status dots and radial biometric gauge arcs.

## Components

### Buttons
- **Primary Tactical Action**: Background `#FF5500`, label text `#0A0D12` in `Sora` 700 uppercase (`label-md`). 4px border radius. Hover introduces a high-potency volt flare (`#CCFF00`) or intensified edge glow (`box-shadow: 0 0 16px rgba(255, 85, 0, 0.45)`).
- **Secondary Instrumentation Action**: Background `#121620`, 1px boundary of `rgba(255, 255, 255, 0.12)`, text `#FFFFFF`. Hover transitions border to `#FF5500` with text `#FF5500`.
- **Ghost Data Action**: Minimal transparent substrate, 1px border `rgba(204, 255, 0, 0.3)`, text `#CCFF00` with monospaced bracket delimiters (`[ VIEW LAB HPLC ]`).

### Cards & Telemetry Displays
- **Glassmorphic Analytical Pods**: Background `rgba(18, 22, 32, 0.75)`, 16px background blur, perimeter edge stroke of `rgba(255, 255, 255, 0.08)`. Headers contain micro-category indices (`SEC.04 // LAB SPEC`).
- **Product & Formula Pod**: Top edge features a 2px dynamic status strip in `#FF5500` (In Stock / High Demand) or `#CCFF00` (Batch Certified).

### Chips & Analytical Badges
- **Nutritional / Bioactive Tag**: Compact padding (`2px 8px`), background `rgba(255, 85, 0, 0.08)`, border `1px solid rgba(255, 85, 0, 0.3)`, text `#FF5500` in `label-sm`.
- **Certification Pill**: Background `rgba(204, 255, 0, 0.08)`, border `1px solid rgba(204, 255, 0, 0.35)`, text `#CCFF00` with a leading 4px neon verification pip.

### Inputs & Select Fields
- **Data Inputs**: Background `#0E121A`, border `1px solid rgba(255, 255, 255, 0.1)`, typography `Hanken Grotesk` 14px in `#FFFFFF`. Placeholder text `#475569`. Focus shifts border instantly to `#FF5500` with a 2px inner optical glow.

### Checkboxes & Segmented Toggles
- **Checkboxes**: Squared 16x16px frame with 2px radius, unselected `rgba(255, 255, 255, 0.1)`. Selected state fills with `#FF5500` displaying an obsidian angled check glyph.
- **Segmented Formula Selector**: Mechanical segmented strip in `#0A0D12` container; active segment transitions to `#1A1F2C` with an active 1px perimeter and amber text readout.

### Domain-Specific Components
- **Supplement Facts Data Matrix**: Monospaced tabular container with alternating row shades (`rgba(255, 255, 255, 0.02)`), active daily value micro-bars in `#CCFF00`, and laser amber percentage indicators.
- **Batch Authenticity Certificate Badge**: Tamper-proof visual lockup with micro QR anchor, holographic metallic border gradient, and third-party laboratory timestamp.
